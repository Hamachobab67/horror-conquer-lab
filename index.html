관리자 도구

Google 계정으로 로그인해야 사용할 수 있어.

안내: 영상은 Supabase 공유 데이터베이스에 저장돼. 관리자 권한이 확인된 계정만 추가·수정·삭제할 수 있어. 설정이 완료되기 전에는 저장 작업을 진행하지 마.
유튜브 링크 입력 후 영상 정보를 자동 조회할 수 있어. API 키가 없으면 직접 입력해 줘.
자주 쓰는 키워드는 눌러서 추가하고, 새로운 문구는 아래에서 등록할 수 있어.
등록된 공통 키워드가 없어.

항목별 평가 (0~5점, 0.5점 단위)

키는 이 브라우저에만 저장돼. 공식 API를 사용하려면 Google Cloud에서 YouTube Data API v3를 활성화하고 API 키를 발급받아야 해. 키를 HTML 파일에 직접 적어 GitHub에 올리지는 마.

유튜브 링크를 입력하면 썸네일이 자동 표시돼. API 키를 설정하면 제목·영상 길이·업로드 날짜·설명을 조회할 수 있어. 자동 조회가 실패해도 모든 항목은 직접 입력하거나 수정할 수 있어.

랜덤 영상 추천

HOW TO USE

이용 가이드

공포 요소와 평가 점수를 확인하고, 자신에게 맞는 영상을 선택해 보세요.

사이트 이용 방법

  1. 영상 카드에서 제목과 게임 이름, 등록된 공포 요소 평가를 확인할 수 있습니다.
  2. 카드를 선택하면 상세 정보와 평가 항목별 점수를 확인할 수 있습니다.
  3. 검색·정렬·공포 요소 필터와 평가 완료 필터를 이용해 관심 있는 영상을 찾아보세요. 랜덤 추천에서는 평가 완료 영상만 선택할 수도 있습니다.
  4. 평가는 영상의 모든 장면이 동일한 강도로 무섭다는 뜻이 아닙니다. 영상에 등장하는 공포 요소를 미리 살펴보기 위한 참고 정보입니다.

평가 점수 안내

스토리 항목은 0~5점 외에 ‘스토리 없음’을 선택할 수 있으며, 이는 평가 완료로 처리해요. 스토리를 제외한 공포 요소 점수는 영상 전체의 평균이 아니라, 영상에서 등장하는 가장 강한 장면의 강도를 기준으로 매겨요. 특정 장면의 점수가 높더라도 영상 내내 같은 강도의 공포가 이어지는 것은 아닐 수 있어요. 평가는 0~5점이며 0.5점 단위예요.

랜덤 추천에서는 공포 강도를 다음과 같이 분류해요. 낮음: 0~1.5점 · 중간: 2~3.5점 · 높음: 4~5점. 미평가 항목은 어떤 구간을 선택해도 추천 후보에서 제외하지 않아요.

스토리

높을수록 긍정적인 항목이에요. 이야기의 흥미, 전개, 구성, 결말이 얼마나 인상적이고 잘 짜여 있는지 평가해요.

유혈·시체 표현

피, 출혈, 시체, 절단, 살해 장면처럼 죽음이나 신체 손상이 얼마나 직접적이고 적나라하게 표현되는지 평가해요.

신체 기괴함

피가 많지 않아도 피부가 벗겨지거나 근육이 드러난 모습, 비정상적으로 변형된 신체, 징그러운 좀비·괴물 외형처럼 시각적으로 불쾌하거나 기괴한 묘사를 평가해요.

예: 파피 플레이타임 챕터 3의 딜라이트

점프 스케어

갑작스러운 등장, 화면 변화, 큰 소리 등으로 놀라게 하는 장면 중 가장 강렬한 장면의 강도를 평가해요. 놀라게 하는 횟수보다는 한 번의 강도에 초점을 맞추며, 잦은 점프 스케어가 불안하거나 부담스러운 분들을 위해 발생 빈도가 높은 경우 특이사항에 별도로 기재해 두었어요.

심리적 긴장·불안

불길한 분위기, 불안감, 음산한 소리, 불확실성, 심리적으로 압박하는 연출의 강도를 평가해요. 백룸이나 드림코어처럼 낯설고 비현실적인 공간과 기묘한 분위기에서 느껴지는 불안감도 포함해요.

추격·도주 압박감

적에게 쫓기거나 도망쳐야 하는 상황, 숨거나 탈출구를 찾아야 하는 장면에서 느껴지는 긴박함과 압박을 평가해요.

평가는 운영자가 영상을 보고 기록한 주관적인 참고 정보예요. 사람마다 무섭게 느끼는 요소는 다를 수 있어요. 미평가는 아직 점수가 등록되지 않았다는 뜻이며, 랜덤 추천의 강도 조건에서는 후보에 포함돼요.

팬이 직접 기록하는 비공식 영상 가이드입니다. 영상 재생은 유튜브 원본 페이지에서 이루어집니다.

나에게 맞는 공포게임 찾기

어떤 공포 요소가 특히 무섭게 느껴지시나요? 답변을 바탕으로 해당 요소의 점수가 낮은 영상부터 확인할 수 있습니다.

무섭게 느껴지는 정도를 선택해 주세요. 답변은 언제든 다시 설정할 수 있습니다. 응답하지 않은 항목은 우선순위 계산에서 제외됩니다.
